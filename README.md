# The Crowd Tape

Daily **US stock-market crowd sentiment** from public posts — Traditional Chinese + English.

**Live site:** [https://thecrowdtape.com/](https://thecrowdtape.com/?utm_source=github&utm_medium=repo&utm_campaign=readme)

美股群眾情緒／另類數據日更站。

## What this is

We track a curated set of market voices (mainly on X), summarize consensus and outliers, and publish a bilingual dashboard. Not investment advice — a tape of what the crowd is saying.
